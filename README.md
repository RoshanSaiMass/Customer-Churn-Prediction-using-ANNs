The following model is a customer churn prediction model.
It uses different aspects of a given bank to check if the customer remains or exits based on different factors. 
A lot of factors were not relevant like the customer id and the row number, as each value was unique so its contribution in prediction would have been minimal to 0.
We have implemented the prediction model using ANN.
The architecture of the model can be seen in the code itself.
Note->The model is a raw output of recent learnings and hasn't been optimised, but will soon be.

The given jupyter notebook has all the libraries that were used in the prediction model.
